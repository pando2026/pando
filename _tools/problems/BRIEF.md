# 나라별 핵심 문제 카드 조사

판도 국가 화면 맨 위 '한눈에 보는 문제'에 그 나라가 **지금(2026-10) 가장 크게 앓는 문제 3개**를 카드로 보여준다. 카드를 누르면 '왜?' 원인 사슬(결과 ← 직접 원인 ← 구조)이 펼쳐진다. 오늘은 2026-10-12. `/home/claude/pando/CLAUDE.md` 취재 원칙을 따른다(당사자 공식 자료 우선, 상대측 대조, 지어내기 금지, 학습 지식은 최근 사건의 근거가 될 수 없음).

먼저 읽을 것(사이트에 이미 있는 자료 — 여기서 출발하고 최신 상황만 확인해 보강):
`data/contexts.json`(그 나라 '지금 상황'), `data/civics.json`의 conflicts, `data/fights.json`, `data/decisions.json`(의사결정 구조 — '구조' 단계에 활용).

입력 `in-<n>.json`: 국가코드 목록. 출력 `out/problems-<n>.json`:
```json
{"TR":{"asOf":"2026-10-12",
 "items":[
  {"area":"경제","topic":"물가","title":"물가 30% 안팎에서 고착","fact":"9월 소비자물가 29.73%로 5년 만에 30% 아래, 기준금리 37%",
   "severity":"high","since":"2021",
   "why":{"result":"물가 30% 안팎, 리라 약세","cause":"한 문장: 직접 원인(누가 무엇을 했나)","structure":"한 문장: 그 원인을 낳은 구조(제도·지정학·경제 구조)"},
   "link":"economy",
   "sources":[["TÜİK","Tüketici Fiyat Endeksi, Eylül 2026 (소비자물가지수 2026년 9월) · 2026-10-03","https://..."]]}
 ],
 "next":[{"date":"2026-10-23","text":"중앙은행 금리 결정"}]}}
```
규칙
- `items` 정확히 3개, 가장 심각한 순서. 분야(`area`)는 경제·정치·안보·외교·사회·인권 중 하나, `topic`은 2~4자 소분류.
- `title` 20자 안팎(명사형으로 끝내도 됨), `fact` 40자 안팎 — **숫자·날짜 하나 이상**.
- `severity`: high(나라 전체를 흔드는 문제: 전쟁·내전·통화위기·정권 위기) / mid(구조적이지만 당장 폭발은 아님).
- `why` 세 칸은 각 한 문장. 사실과 주장을 구분(누가 그렇게 말했나). 원인이 다툼거리면 양쪽 공식 입장을 짧게 함께.
- `link`: 더 볼 탭 — "economy" | "politics" | "military" | "conflict" | "decisions".
- `sources` 1~3개, 실제로 연 페이지(당사자 정부·통계청·중앙은행 > 통신사 > 연구기관 > 위키백과). 외국어는 원제 + (한국어 번역 제목).
- `next`: 앞으로 3~12개월 안의 **확정된** 일정 0~2개(선거·재판 선고·협상 시한·중앙은행 결정·채무 상환일). 날짜를 연 페이지에서 확인한 것만. 없으면 [].
- **검색은 끝까지**(CLAUDE.md 18번: 막히면 다른 출처·언어·경로를 모두 시도한 뒤에만 '자료 없음')(공유 한도). 나머지는 WebFetch로 직접 연다. 429면 1분 쉬고 재시도.
끝나면 JSON 문법 확인 후 나라별 "items 3, next n"만 짧게 보고.
