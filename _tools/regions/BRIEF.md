# 지역 기반 정당 조사

큰 나라·연방국가에서는 특정 지역(주·州, 민족 거주지)을 기반으로 결성되거나 그 지역에서만 강한 정당이 있다(예: 캐나다 퀘벡블록, 스페인 바스크민족당·준츠, 영국 SNP, 독일 CSU(바이에른), 인도 DMK(타밀나두)·TMC(서벵골), 이라크 KDP(쿠르디스탄)). 판도 사이트의 각 나라 의회 화면 설명에 이걸 넣는다. 오늘은 2026-10-11.

입력 `in-<n>.json`: {국가코드: {groups:[사이트에 표시되는 정당 이름(한국어)], orig:{이름: 원어 이름}}}
출력 `out/regions-<n>.json`:
```json
{"CA":{"summary":"2~3문장: 이 나라 정당 구도에서 지역이 어떤 역할을 하는지(지역주의·민족·언어·연방제). 사실만.",
  "parties":{"퀘벡블록":{"region":"퀘벡주","kind":"지역 정당","note":"한 문장: 어디서 왜 생겼고 무엇을 주장하는지","source":["Wikipedia","Bloc Québécois","https://en.wikipedia.org/wiki/Bloc_Qu%C3%A9b%C3%A9cois"]}},
  "strongholds":[{"party":"자유민주당","region":"…","note":"전국 정당이지만 특정 지역 지지 기반이 뚜렷한 경우 한 문장"}],
  "source":["기관","제목","url"]}}
```
규칙
- `parties`의 키는 입력 `groups` 이름과 **글자까지 똑같이**. 지역 기반 정당만 넣는다(전국 정당은 넣지 않음). `kind`: "지역 정당" | "민족·언어 정당" | "지역 분리·자치 정당" 중 하나.
- `strongholds`(선택, 최대 4): 전국 정당이지만 지역 기반이 뚜렷한 경우(예: 한국 영남·호남, 미국 남부·해안, 일본 오사카의 일본유신회). 출처가 있는 경우만.
- 지역 기반 정당이 사실상 없는 나라는 `summary`만 쓰고 parties는 {}.
- 출처: **WebSearch 금지**(한도 소진). WebFetch로 영어 위키백과(정당 문서, "Politics of X", "List of political parties in X") 또는 공식 자료를 직접 연다. 429가 나면 1분 쉬고 다시. 추측 금지 — 확인 못 한 정당은 뺀다.
끝나면 JSON 문법 확인 후 나라별 지역 정당 수만 보고.
