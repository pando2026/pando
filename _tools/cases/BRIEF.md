# 부패·선거 부정 사례 조사

판도 국가 화면의 '부패인식지수'와 '선거의 공정성' 점수 옆에 **그 점수를 실감하게 하는 실제 사례**를 접었다 펴는 창으로 보여준다. 오늘은 2026-10-14. `/home/claude/pando/CLAUDE.md` 취재 원칙을 따른다(지어내기 금지, 사실과 주장 구분, 객관적≠중립적: 혐의를 받는 쪽의 공식 반박도 함께).

입력 `in-<n>.json`: 국가코드 목록. 출력 `out/cases-<n>.json`:
```json
{"KR":{"asOf":"2026-10-14",
 "corruption":[
  {"title":"20자 안팎 사건 이름","year":"2016","who":"관련 인물·기관(직책)","status":"유죄 확정|1심 유죄|기소|수사 중|의혹|무죄|사면",
   "text":"2~3문장: 무엇을 했다는 혐의인지, 결과(판결·처벌·사임), 당사자 입장. 날짜·액수 정확히.",
   "sources":[["기관","제목 · YYYY-MM-DD","https://..."]]}],
 "elections":[
  {"title":"…","year":"2024","who":"…","status":"공식 확인|국제감시단 지적|법원 판결|야당 주장|의혹",
   "text":"2~3문장: 어떤 선거에서 무엇이 문제였는지(표 매수·개표 부정·후보 자격 박탈·야당 탄압·선거 폭력·선거구 조작 등), 누가 그렇게 판단했는지(선관위·법원·OSCE/EU 감시단 등), 정부·선관위 반박.",
   "sources":[["…","…","https://…"]]}]}}
```
규칙
- 나라마다 corruption 2~4건, elections 0~3건. **최근 10년(2016~2026) 위주**, 그 나라 정치를 이해하는 데 중요한 것부터. 선거가 없는 나라는 elections에 '선거 자체가 없음/중단'을 1건으로 써도 된다(근거 필수).
- 개인 범죄가 아니라 **공직·공공 권력과 관련된** 부패·선거 사건만. 확정되지 않은 혐의는 status를 정확히(의혹/수사 중/기소) 쓰고 단정하지 않는다.
- 출처 1~2개 필수, 실제로 연 페이지: 법원·검찰·선관위·감사기관·국제감시단(OSCE/ODIHR, EU EOM, 카터센터) 보고서 > 통신사 > 영어 위키백과. 외국어 자료는 원제(한국어 번역).
- **WebSearch는 나라당 최대 2번**(공유 한도). 429면 1분 쉬고 재시도. 확인 못 하면 빼라.
끝나면 JSON 문법 확인 후 나라별 "corruption n, elections n"만 짧게 보고.
