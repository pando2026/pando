# 나라별 의사결정 구조 조사

판도 국가 화면(정치·의회 탭)에 **"이 나라에서 결정은 어떻게 내려지나"**를 넣는다. 독자는 한국 대학생: 짧고 구체적으로. 오늘은 2026-10-12. `/home/claude/pando/CLAUDE.md` 취재 원칙을 따른다(지어내기 금지, 2026년 현재 상태 확인).

입력 `in-<n>.json`: [[국가코드, 영어 이름, 사이트의 정치 체제 표기]]. 출력 `out/decisions-<n>.json`:
```json
{"KR":{
 "summary":"2문장. 이 나라에서 중요한 결정을 실제로 누가 내리는지(공식 구조 + 실제 권력의 무게중심).",
 "power":[{"who":"대통령","how":"직선 5년 단임","holds":"행정부 수반·국군 통수권·법률안 거부권"},
          {"who":"국회","how":"단원제 300석, 4년","holds":"입법·예산 확정·탄핵소추"}],
 "flows":{
  "law":["정부 또는 의원 10명 이상이 법률안 제출","소관 상임위 심사 → 법제사법위 체계·자구 심사","본회의 재적 과반 출석·출석 과반 찬성","대통령 15일 안에 공포 또는 재의 요구 → 재적 과반 출석·출석 2/3로 재의결하면 확정"],
  "budget":["정부가 회계연도 시작 120일 전 예산안 제출","예산결산특위 심사(국회는 증액·새 항목 신설 불가)","본회의 의결(회계연도 30일 전까지)"],
  "war":["대통령이 국군 통수","선전포고·해외 파병은 국회 동의","조약 비준은 국회 동의"]
 },
 "checks":["헌법재판소 위헌·탄핵 심판","헌법 개정은 국회 2/3 의결 + 국민투표"],
 "informal":"공식 절차 밖에서 결정에 큰 힘을 쓰는 존재가 있으면 1~2문장(예: 공산당 정치국, 군부, 왕실, 최고지도자·종교기구, 지배 가문). 없으면 \"\".",
 "sources":[["기관","제목 · 날짜","https://..."]]
}}
```
규칙
- 주권국가: 위 형식 전부. `power` 2~5개, `flows` 각 3~5단계(짧은 구절, 단계마다 누가·무엇을·몇 표/며칠), `checks` 1~4개.
- **실제와 형식이 다른 나라**(일당제, 군정, 절대왕정, 신정, 과도정부)는 summary와 informal에 실제 결정 주체를 분명히 쓰고, flows도 실제로 거치는 단계로 쓴다(예: 중국 법률 = 당 중앙 결정 → 전인대 상무위 심의 → 전인대 표결). 2026년 군정·과도기 상황(쿠데타, 의회 해산, 헌법 정지)은 반드시 확인.
- **영토·속령·자치령**(예: 그린란드, 푸에르토리코, 홍콩, 지브롤터, 남극): summary 1~2문장 + `power` 1~3개(본국과 자치정부의 권한 구분) + `flows.law`만, 나머지는 생략 가능. 사람이 살지 않는 곳은 summary만.
- 숫자(의석 수, 정족수, 기한)는 헌법·공식 자료에서 확인한 것만. 확인 못 하면 숫자를 빼고 쓴다.
- 출처 1~3개, 실제로 연 페이지: Constitute Project(constituteproject.org) 헌법 원문, 의회 공식 사이트, IPU Parline, 영어 위키백과 "Politics of X"/"Government of X"/"Legislature of X".
- **WebSearch 사용 금지**(한도 공유). WebFetch로 직접 연다. 429면 1분 쉬고 재시도.
끝나면 JSON 문법 확인 후, 처리한 나라 수와 '2026년에 체제가 바뀐 나라'만 짧게 보고.
